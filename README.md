# 數學進化獸

給小朋友玩的網頁數學遊戲（十以內加減），iPad / 電腦皆可。

- 三個角色：小暴龍、小海怪、小男孩，各有 4 個進化型態（Lv.5 / 10 / 15 進化）
- 每次任務 3 關 × 2 題：數東西（蘋果、小豬、鴨子…）→ 錢幣（1 元 / 5 元、付錢、找零）→ 純數字算式（3 + 3 = ?）
- 繁體中文 / English（文字與語音），預設跟瀏覽器語言，可在設定切換
- 過關得經驗值 → 升級三選一卡片（變強壯、長高、盔甲、翅膀、火焰之力……共 12 種，都會改變外觀）→ 打倒怪物 → 升級 / 進化動畫
- 答錯不懲罰：標數字 → 帶著數 → 提示答案
- 純靜態網頁，無需建置：`python3 -m http.server 8770` 後開 http://localhost:8770

美術全部以程式繪製的 SVG 向量圖，語音使用瀏覽器內建 zh-TW 語音。
